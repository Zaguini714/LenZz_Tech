# LenZz Websites

A modern one-page website for a website-building service. It includes a polished hero section, service cards, style previews, launch process, package ideas, FAQ, and a contact call to action.

## Files

- `index.html` - page content and structure
- `styles.css` - layout, colors, animation, and responsive design
- `script.js` - loading screen, scroll reveal, active navigation, and card hover motion
